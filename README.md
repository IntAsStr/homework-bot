# homework_bot
python telegram bot

Бот для отслеживания статуса проверки домашних работ на платформе Яндекс.Практикум.
- Автоматическая проверка статуса домашних работ через API Практикума
- Уведомления в Telegram об изменении статуса.

## 🚀 Локальный запуск
1. Склонировать репозиторий:
   ```bash
   - git clone https://github.com/ваш-репозиторий.git
   - cd homework-bot
   - Запустить виртуальное окружение
   - Установить зависимости из requirements.txt
   - Запустить бота командой python homework.py
